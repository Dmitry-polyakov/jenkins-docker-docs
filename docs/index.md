# 🚀 Развертывание Jenkins через Docker Compose

## 📖 Введение
Данная инструкция описывает процесс развертывания Jenkins с использованием Docker Compose на серверной версии Linux (например, Ubuntu). Все команды выполняются в терминале серверной версии Linux.

!!! info "Предварительные требования"
    - ОС: Ubuntu Server 22.04 LTS (или новее)
    - Права: Доступ к sudo
    - Ресурсы:
      - Минимум 2 ядра CPU
      - 4 ГБ RAM
      - 20 ГБ свободного места на диске
